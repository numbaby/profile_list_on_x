# 潘建伟院士：没有任何一个国家关起门来，还能一直保持科技领先，我们一定要竭尽所能保持国际交流合作

> 原创 是李姐呀 · 2026年11月15日 10:58 · 广东

潘建伟说了句实在话：没有任何一个国家关起门来，还能一直保持科技领先。

有人觉得我们水平已经很高了，不用再向西方学，自己关起门也能行。潘建伟坚决不赞成。

这话不是不自信，是清醒。

翻历史，关起门来的教训一抓一把。清朝闭关锁国，人家工业革命了，我们还在天朝上国梦里。等炮舰开到门口，才发现差了一整个时代。日本锁国两百年，要不是黑船来敲门，可能还在江户时代打转。

苏联也试过。冷战时期搞封闭体系，自己的标准、自己的路线，跟西方几乎不来往。军工能上天，可民用科技一塌糊涂，计算机、半导体、互联网，全落了后。等门打开，差距已经追不上了。

科学这东西，从来不是一国的事。牛顿站在伽利略肩膀上，爱因斯坦读着麦克斯韦的论文，杨振宁李政道拿诺奖，靠的是芝加哥和普林斯顿的学术圈。人类基因组计划，六国科学家一起干；引力波探测，几十个国家上千人参与；新冠疫苗，从序列公开到全球接种，谁也没关着门搞出来。

一个大脑再聪明，也顶不了一群大脑碰撞。潘建伟说，人类文明的进步，是全球聪明大脑一起攒的。这话不虚。

当然，有人会说，两弹一星不也是在封锁下搞出来的？对，可别忘了，钱学森、邓稼先那批人，本身就是从国外学成回来的。他们带回来的知识，是国际交流的产物。封锁逼出了自主，可自主的底子，还是人类共同的科学积累。

真正该分清楚的，是两件事：自主和封闭，不是一回事。

自主是核心东西自己攥着，不被卡脖子。封闭是连学都不学了，连交流都不做了。前者是底线，后者是自断后路。

中国这些年，量子通信、航天、高铁，都有自主的东西，可哪一样离得开国际交流？量子通信的论文发在国际期刊上，航天合作跟欧洲、俄罗斯都有往来，高铁技术最早也是引进消化再创新。

关起门来，短期可能看不出问题，十年二十年，就露馅了。科技的迭代速度，等不起。

真正的大国自信，不是不怕开门，是敢开门。开了门，能学别人的，也能让别人学自己的。有来有往，才叫交流。

那些在实验室里跟外国同行视频会议的科研人员，在国际会议上用英文讲自己成果的年轻人，在海外访学又回来的学者，他们不关心什么"关门""开门"的争论，只关心这个领域最前沿的东西，能不能第一时间拿到、学到、用上。

拿得到，就追得上。拿不到，就慢半拍。半拍在科技上，可能就是一代人的差距。

潘建伟那句话，说到底是个提醒：领先不是关出来的，是比出来的。你在一群高手里还能站前面，那才叫真领先。把高手的门关上，自己跟自己比，赢了也是虚的。

门得开着。开着，才有比较；有比较，才知道自己到底站在哪儿。
